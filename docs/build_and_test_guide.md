# Auto Yon Koma 编译与测试指南

该系统基于前后端分离架构，并在底层部署了高配的智能体矩阵引擎。以下内容将指引您如何极速在本地将整套服务启动运转并进行全链路验收。

## 1. 环境准备清单
* **Go 环境**: `>= 1.21` (推荐使用最新版，提供强大泛型支持)
* **Node.js**: `>= 18.x` (含 NPM)
* **数据库驱动**: 根深于 SQLite，后端执行启动时将依靠 GORM AutoMigrate 实现零配置自动创建，无需独立安装关系型外接服务库。

---

## 2. 后端服务端 (Backend) 编译与启动

请新打开一个命令终端，定位于代码仓库内的 `backend/` 层级：

```bash
cd backend
```

### 步骤 A：映射基础配置
系统根深依赖 LLM （大语言模型与生图大模型）。请建立您的专属配置文件：
```bash
cp config.example.yaml config.yaml
```
此时请用编辑器打开 `config.yaml`，填入您的 OpenAI（用于 Agent 对话拆解剧本和质检）、及 NanoBanana / 生图适配提供商的核心秘钥（API Key）。

### 步骤 B：解决依赖并唤醒
运行下述命令同步标准库并起跑服务器：
```bash
go mod tidy
go run cmd/server/main.go
# 默认讲无缝运行于 http://localhost:8080 端口！
```
> **提示**: 后台启动时，如果日志打出 `[Auto Migrate] Models synced successfully.`，意味着表单和实体已经自愈全数建立完毕。

---

## 3. 前端客户端 (Frontend) 构筑与运行

再次打开一个终端，切换入前端构建大帐篷内：

```bash
cd frontend
```

### 步骤 A：安装包网
前端采取了 React + Vite 的高效解构模式，并额外加装了负责支持解耦画布引擎的组件族 (`react-konva`)：
```bash
npm install
```

### 步骤 B：调试态启动
```bash
npm run dev
# 默认映射将于 http://localhost:5173
```
> **注意**: 我们的跨域拦截已被处理妥当——前端侧的 `vite.config.ts` 已内置针对此后端的 proxy（/api 映射至 :8080）。一键直连！

---

## 4. 极致全链路功能导览 (E2E Walkthrough)

请确保系统在双核运行中，并且通过浏览器踏入基站：**`http://localhost:5173`** 

**第一幕：驻神（鉴权流）**
* 用任意虚构的邮箱做新客注册。我们严格搭载了防小号策略，需于终端跟随日志输出查看生成的 TOTP 初始化私钥绑定虚拟凭证器打通 2FA！

**第二幕：宇宙的缔结（预演阶段）**
* 前往 **Character Library**：像设定 TRPG 一样建立您世界框架里的一名骨干主角（记得写上详实的日文名及体貌暗语以利生图）。
* 前往 **Series Universe** 高阶仪盘：在宏大面板里新建一个“连载集合归档”。它的作用是在连载漫的“第一卷、第二卷”承接时留下一份常驻设定的锁死状态。

**第三幕：降级为神仙级的自动脚本分镜（拆解）**
* 点选进入 **Script Studio** 。贴上一段五六十字的桥段日常。点击 `Parse Storyboard`；
* 此时内部的 **Agent 3 开天** + **Agent 7 布局大师** 被联袂唤醒，会在左侧吐出分好的文本，又在右侧将你的桥段严格转化为四层结构树：`Visual Desc (指示语)`、`Dialog` 还有绝版的 `Layout (边框越界指南)`！在此您可点选锁扣微调，或是人工内联请求 LLM 小助手修改！

**第四幕：烈焰锻图出厂**
* 进入最终生成面板。点击开启造物。
* 此时底层流转进了高度解耦的任务 `TaskQueue`，大批量拉起生成请求，而最为残酷的是 **Agent 6 (QC Reviewer 审核官)** 的看图拦截器：遇到生成扭曲、逻辑不契合的内容，该协程会当场重载重新绘制。

**第五幕：终极的画布，脱格降临！**
* 完成时点击面板最底端的 **Advanced Composer** 进入进阶控制台。
* 这里基于纯粹的 React Konva 构建！在以往单薄的一帧内死板拼合中解脱出来：拖动独立分镜的底背，四处排版浮现带阴影框的对话气泡以制造压迫感与留白——这正是真正的排版工作台。
* 对于有二创分发者：顶部开关关闭即成剥离字模的“素稿净版”，同时能够使用 **Save .ayk** 将画布整体的逻辑节点抽成工程存储至硬盘。

一切尽收于此。祝体验愉快！
